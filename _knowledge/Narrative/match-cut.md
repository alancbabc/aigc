# Match Cut 匹配剪辑

## 层级
场景级 (Scene-Level)

## 描述
通过两个镜头间的构图相似性（形状、颜色、运动方向），实现场景或时间的平滑跳跃。

核心特点：
- 视觉上的无缝衔接
- 不需要溶解或黑场
- 常用于对比或隐喻

## 决策
使用条件：
1. 需要时空跳跃但保持流畅
2. 两个场景有视觉关联元素
3. 强调对比或相似性
4. 需要隐喻或象征

满足 ≥2 个条件 → 使用匹配剪辑

## 类型

### 构图匹配
镜头A和镜头B有相似的画面结构：
- 门 → 窗户
- 杯子 → 地球
- 孩子的眼睛 → 动物的眼镜

### 动作匹配
动作的延续或对应：
- 跳起 → 落下
- 开门 → 走进
- 扔出 → 接住

### 色彩匹配
颜色上的呼应：
- 红色花朵 → 红色跑车
- 橙色夕阳 → 橙色房间

## 结构

### 镜头A
- 包含匹配元素
- 动作或构图完成中

### 匹配点
- 视觉元素相似
- 切换时机要准

### 镜头B
- 新场景/时间
- 延续或对比

## 约束

- 匹配点要明显
- 不要强行匹配
- 保持镜头短促
- 避免过度使用

## 经典例子
- 2001: A Space Odyssey：骨头 → 飞船
- The Lion King：狒狒举起辛巴 → 雕像举起狮子

- 可以做隐喻表达
