# Season Transition Shot 季节变化镜头

## 层级
场景级 (Scene-Level)

## 描述
单镜头内通过环境变化（季节转换）表现时间流逝，角色在同一位置但经历岁月变迁。

核心特点：
- 单一连续镜头完成
- 空间位置基本不变
- 季节/环境明显变化
- 人物可能成长/变老

## 决策
使用条件：
1. 需要表现长时间跨度（如几年、几十年）
2. 强调时间的残酷或成长的美好
3. 空间位置有特殊意义（如角色坚守的地方）
4. 需要诗意化的时间表达

满足 ≥2 个条件 → 使用季节变化镜头

## 结构

### 起点
- 设定初始季节（通常春季）
- 角色处于标志性位置
- 初始状态（年龄、装扮）

### 季节推进
按顺序：
- 春 → 夏 → 秋 → 冬 → 春（循环）
或
- 秋 → 冬 → 春（单一方向）

变化要素：
- 植被（绿叶 → 落叶 → 雪花 → 新芽）
- 光线（暖 → 冷 → 暖）
- 天气（晴 → 雨 → 雪）
- 色调（绿 → 金 → 白）

### 人物变化
- 年龄增长
- 装扮变化
- 姿态变化
- 可能离开或归来

### 终点
- 最终季节
- 最终状态
- 与起点形成对比

## 约束

- 镜头运动要平滑连续
- 不要切换场景
- 季节变化要自然过渡
- 人物变化要与季节对应

## AI 生成提示

适合 AI 视频生成的特点：
- 单镜头连续，适合 5s 视频模型
- camera orbit + environment change 组合
- 人物可以相对静态
- 季节变化可以通过 prompt 控制
