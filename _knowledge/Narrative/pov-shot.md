# POV Shot 第一人称视角切换

## 层级
场景级 (Scene-Level)

## 描述
通过第一人称（POV）和第三人称视角的来回切换，让观众一会代入角色视角，一会旁观。

核心特点：
- 第一人称：观众看到角色所见的画面
- 视角切换：POV ↔ 第三人称
- 增强沉浸感和情绪传递

## 决策
使用条件：
1. 需要观众代入角色内心
2. 展现角色看到的事物
3. 制造悬念或对比
4. 外化角色的心理状态

满足 ≥2 个条件 → 使用 POV 切换

## 结构

### POV 视角
- 从角色眼睛看出去
- 画面带有角色主观色彩
- 可能带有呼吸、心跳等音效

### 切换
- 典型的 POV 模式：POV → 角色反应 → POV → 角色反应
- 或 POV → 第三人称全览 → POV
- 切换节奏根据情绪需要

### 第三人称视角
- 常规的旁观视角
- 展示角色在场景中的行为

## 常见模式

### 模式一：POV → 角色反应
```
POV（看到危险）→ CUT → 角色惊恐表情 → POV（继续看）
```

### 模式二：POV → 第三人称
```
POV（走过走廊）→ CUT → 第三人称看到整个场景 → POV（继续走）
```

### 模式三：纯粹的 POV 段落
整个场景都是 POV，展示角色视角下的世界

## 约束

- POV 镜头要有意义（看到重要信息或情感）
- 不要过度使用，会让观众疲劳
- POV 和第三人称要有明显区别
- 可以通过画面色调、边框等区分 POV

## 经典例子

- The Silence of the Lambs：克劳福德探员给克拉丽丝看现场照片
- Hardcore Henry：第一人称贯穿全片
-Spider-Man: Homecoming：蜘蛛侠视角

## AI 生成提示

适合 AI 视频生成的特点：
- 需要两个视角的素材
- 切换点要清晰
- POV 视角可以用主观效果（轻微晃动、呼吸声）增强代入感
