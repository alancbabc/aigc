# Summary Scene 概述场景

## 层级
场景级 (Scene-Level)

## 描述
概述场景压缩一段时间内的情节，略过细节，只保留关键信息。

与标准场景不同，概述场景不展现完整冲突过程，而是快速带过。

## 决策
使用概述场景的条件：

1. 故事中有时间跨度大的情节
2. 这些情节不是重点，不需要细节
3. 需要快速建立时间流逝
4. 避免读者觉得叙事拖沓

满足以上条件 → 使用概述场景

## 结构

### 压缩时间段
明确场景跨越多长时间
- 几分钟、几小时、几天、几年

### 关键事件列表
列举期间发生的关键事件
- 1-3 个核心事件
- 不需要展开细节

### 结果状态
场景结束时的时间点
- 角色到达的新状态
- 为下一个场景做铺垫

## 写作特点

- 句子简洁，信息密集
- 不描写对话细节
- 不展示内心活动
- 只呈现结果，不展示过程

## 约束

- 不要过度使用
- 重要情节必须用标准场景
- 概述场景后通常接详细场景
- 保持叙事节奏平衡
