# Montage Structure 蒙太奇结构

## 层级
场景级 (Scene-Level)

## 描述
本结构适用于需要表现时间流逝、情感积累、角色成长、环境变化或在有限叙事空间内进行平行推进的叙事段落。

当故事强调过程、对比、节奏或主题强化而非单一持续戏剧冲突时使用。

结构范围规则：
- 一个蒙太奇等于一个场景
- 不能跨越多个场景
- 是一个自成一体的压缩叙事单元

## 决策
按以下标准评估：
1. 时间压缩需求
2. 过程重于事件
3. 重复或模式
4. 情感积累
5. 多地点或平行
6. 缺乏单一核心冲突
7. 高潮前的铺垫功能

满足 ≥3 个条件 → 使用蒙太奇结构
满足 <3 个条件 → 使用标准场景结构

## 结构

结构抽象为：

**触发** → **片段1** → **片段2** → **片段3** → … → **升级高潮片段** → ** payoff/过渡**

### 1. 触发（情感或目标启动）
关键词：
- 决心
- 危机
- 欲望
- 时间流逝
- 情感爆发前的信号

写作要求：
- 必须清晰建立角色想要什么或失去什么
- 以强烈的情感线或生动意象开始
- 不超过一段
- 不要扩展成完整场景

### 2. 碎片化序列
数量：
- 3-7 个片段

每个片段必须：
- 包含一个清晰的动作
- 包含一个清晰的视觉画面
- 简短（1-3句话）
- 避免冗长对话
- 避免背景解释

允许：
- 时间跳跃
- 地点跳跃
- 同一动作的重复

连接方式（至少选一种）：
- 情感递进
- 难度递增
- 对比
- 节奏加速

禁止：
- 详细的因果解释
- 长的心理分析
- 连续对话
- 逻辑/说明性叙述

### 3. 渐进式升级
要求：
- 每个片段必须比前一个更强
- 冲突或压力逐渐增加
- 句子节奏变得更短或更密集
- 最后一个片段明显达到峰值

### 4. 高潮片段
必须包含：
- 强烈的视觉意象
- 强烈的情感
- 强烈的动作

特征：
- 与之前片段明显对比
- 即将变化的感觉

### 5. Payoff / 过渡
需要明确的结果：
- 成功
- 失败
- 情感释放
- 环境变化
- 过渡到下一个主要场景

要求：
- 清晰明确
- 不模糊
- 不要悬而未决
- 不要在此时继续延长蒙太奇

## 约束

- 保持总长度简洁
- 优先动作和画面
- 对话比例 ≤ 10%
- 避免"然后"、"之后"等逻辑连接词
- 不要解释结构
- 不要明确标记为蒙太奇
