# Routine Loop 日常循环

## 层级
场景级 (Scene-Level)

## 描述
通过重复展示日常生活片段，表现时间的流逝或角色状态的微妙变化。

核心特点：
- 同一行为模式反复出现
- 每次有细微变化（天气、表情、环境）
- 最终可能打破循环或持续

## 决策
使用条件：
1. 表现角色的单调生活或日常
2. 需要暗示时间流逝但不用明显数值
3. 强调角色的心理状态（等待、坚守、迷茫）
4. 为后续变化做铺垫

满足 ≥2 个条件 → 使用日常循环

## 结构

### 循环建立
- 展示日常行为模式
- 明确时间背景
- 建立重复的节奏

### 重复 + 变化
每次循环的差异：
- 天气/光线变化
- 角色表情/状态变化
- 环境中细节变化
- 物品/装扮变化

变化要微妙：
- 不要每次都完全不同
- 让观众感受到渐进

### 循环打破（或持续）
- 意外事件发生，打破循环
- 或角色决定离开
- 或循环继续但心态已变

## 约束

- 循环模式要简洁
- 变化要自然细微
- 不要过度解释
- 避免每次都是新场景

## AI 生成提示

适合 AI 视频生成的特点：
- 同一动作可以重复生成
- 每次微调 prompt 即可
- 适合表现内心状态
- 可以和 progress-montage 结合
