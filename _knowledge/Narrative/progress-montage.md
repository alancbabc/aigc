# Progress Montage 进展蒙太奇

## 层级
场景级 (Scene-Level)

## 描述
通过重复展示类似行为的镜头，配合进度/数值不断增加，表现时间流逝、目标接近或能力提升。

核心特点：
- 行为重复但有细微变化
- 进度/数值持续累加
- 节奏逐渐加快
- 最终达成目标

## 决策
使用条件：
1. 需要表现长时间的压缩（如训练、工作、学习）
2. 有明确的数值或进度可衡量
3. 结果是可量化的目标达成
4. 过程本身比结果更重要

满足 ≥2 个条件 → 使用进展蒙太奇

## 结构

### 起点
- 建立角色当前状态
- 明确目标（如：累计10000积分、练成某技能）
- 设定起点数值

### 重复行动 + 数值增加
重复模式：
- 行动A → 数值+10
- 行动B → 数值+20
- 行动C → 数值+50

变化维度：
- 环境（天气、季节、时间段）
- 难度（越来越难）
- 角色状态（更熟练、更疲惫）

### 接近目标
- 数值接近目标值
- 节奏加快
- 画面更有紧迫感

### 达成
- 目标数值达成
- 角色获得成果

## 约束

- 数值/进度必须清晰可见
- 每个镜头要短（2-5秒）
- 避免长对话
- 保持节奏递增
- 不要解释数值变化原因

## AI 生成提示

适合 AI 视频生成的特点：
- 每个 shot 很短
- 不要求强连续性
- 可以重复类似动作
- 数值/进度可用文字或 UI 元素表现
