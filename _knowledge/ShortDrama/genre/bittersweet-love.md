# 虐恋纠葛 Bittersweet Love

## 核心主题
- 替身情人，爱而不得
- 契约恋爱，假戏真做
- 带球跑，多年后回归
- 豪门恩怨，爱恨交织
- 身份悬殊，无法相守
- 「爱你是真的，伤害你也是真的」

## 典型设定

### 常见虐恋设定
- 替身情人（白月光替身）
- 契约婚姻（各取所需）
- 带球跑（多年后回归）
- 身份悬殊（灰姑娘与王子）
- 家族仇恨（杀父之仇）

### 经典套路
- 以为是真爱，结果是替身
- 真相大白，心碎离去
- 豪门婆婆甩支票
- 误会层层，永远错过
- 重逢已是物是人非

## 虐点设计

### 虐心情节
- 发现自己是替身
- 真相被隐藏多年
- 最信任的人背叛
- 家族强烈反对
- 生死相隔

### 虐身心节
- 被误解，被伤害
- 被打，被羞辱
- 失去孩子，失去亲人
- 身患绝症
- 失忆

### 经典台词
- 「你只是她的替身而已」
- 「我不爱你，只是你像她」
- 「滚出我的世界」
- 「这一百万，买你离开」
- 「我恨你，但我更爱你」

## 角色关系

### 标配角色
- 虐心男主：口是心非，后知后觉
- 坚韧女主：痴心不改，被伤透心
- 白月光：完美初恋，回国搅局
- 恶毒女配：各种陷害
- 豪门婆婆：强烈反对

### 关系动态
- 相遇 → 相爱 → 发现真相 → 心碎
- 离开 → 成长 → 回归 → 虐心/圆满

## 情绪曲线

```
第一集：相遇相爱（甜）
第五集：发现真相（虐）
第十集：心碎离开（虐）
第十五集：多年回归（虐/爽）
第二十集：虐心or圆满（根据结局）
```

## 常用叙事结构

1. **相遇**：浪漫相遇，暗生情愫
2. **热恋**：甜蜜相处，感情升温
3. **真相**：发现替身/秘密/误会
4. **伤害**：心碎离去
5. **虐心**：各种错过和误会
6. **结局**：虐心be or 圆满he
