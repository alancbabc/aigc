# 重生逆袭 Rebirth

## 核心主题
- 意外死亡，意外重生
- 回到过去，弥补遗憾
- 重活一世，逆天改命
- 前世仇人，今世加倍奉还
- 前世遗憾，今世全部实现
- 「这一次，我不会再放手」

## 典型设定

### 常见重生设定
- 重生回到高考前
- 重生回到结婚前
- 重生回到大学时代
- 重生回到小时候
- 意外死亡后魂穿

### 金手指
- 携带前世记忆
- 知道未来彩票号码
- 知道即将发生的事
- 拥有前世技能
- 预知股票走向

### 经典套路
- 重生后避开前世陷阱
- 追回前世错过的人
- 搞垮前世的敌人
- 弥补前世的遗憾
- 走上人生巅峰

## 爽点设计

### 逆袭场面
- 学渣变学霸
- 丑小鸭变天鹅
- 穷鬼变富豪
- 单身变人生赢家

### 打脸场面
- 前世仇人 → 提前收拾
- 势利眼亲戚 → 后悔莫及
- 绿茶闺蜜 → 原形毕露
- 负心汉 → 跪求复合被拒

### 名场面
- 「这一次，我不会再让你失望」
- 「属于我的，我会亲手拿回来」
- 「前世你对我爱答不理，现在你高攀不起」
- 「感谢你前世抛弃我」

## 角色关系

### 标配角色
- 重生女主/男主：带着记忆逆袭
- 负心汉/绿茶：前世背叛，今世报复
- 父母家人：这一世好好珍惜
- 贵人相助：遇到的温暖的人
- 忠犬伴侣：前世错过，今世把握

### 关系动态
- 前世 → 今世的弥补
- 敌人 → 提前消灭
- 错过 → 重新抓住
- 遗憾 → 全部实现

## 视觉风格

### 色调
- 回忆灰（前世）
- 重生金（今世）
- 爽感红
- 温暖黄

### 场景
- 回到过去的熟悉场景
- 改变命运的瞬间
- 人生巅峰的高光时刻

### 人像
- 眼神坚定
- 自信从容
- 带着前世记忆的沧桑感

## 情绪曲线

```
第一集：重生回到过去（惊喜）
第三集：避开前世陷阱（暗爽）
第五集：开始逆袭（爽）
第十集：收拾前世仇人（超爽）
第十五集：走上人生巅峰（爽）
第二十集：圆满收官（满足）
```

## 常用叙事结构

1. **死亡/意外**：前世结局
2. **重生归来**：回到过去某个节点
3. **避开陷阱**：改变命运走向
4. **弥补遗憾**：抓住该抓住的人
5. **收拾敌人**：复仇前世仇人
6. **走上巅峰**：人生赢家
