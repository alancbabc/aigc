# 神豪归来 God of Wealth

## 核心主题
- 隐形富豪，隐藏身份
- 废物赘婿，身份曝光
- 超级富二代，体验生活
- 「钱只是个数字」
- 「我花钱，你买单」
- 「全场消费，由赵公子买单」

## 典型设定

### 常见男主设定
- 隐形富二代（家族隐藏身份）
- 废物赘婿（实际是超级豪门）
- 体验生活的富豪（伪装成普通人）
- 意外继承万亿遗产

### 隐藏身份
- 世界首富家族
- 神秘财团继承者
- 隐藏的家族掌门
- 顶级投资人
- 多个马甲叠加

### 经典套路
- 被嘲笑是穷鬼 → 随手一个亿
- 离婚边缘 → 身份曝光
- 家族危机 → 强势接管
- 同学会 → 震惊全场
- 丈母娘态度大转变

## 爽点设计

### 炫富场面
- 随手砸钱买买买
- 「这个店我包了」
- 「全场消费我买单」
- 送车送房送股份
- 银行卡余额吓死人

### 打脸场面
- 势利眼亲戚 → 当场打脸
- 拜金女友 → 后悔莫及
- 嘲讽穷人 → 身份吓尿
- 豪门家族 → 跪求回归
- 情敌 → 被秒成渣

### 护短名场面
- 「我老婆的东西，我买得起」
- 「我们家的女人，不用省钱」
- 「敢欺负我的人，问问我答不答应」
- 「钱能解决的事，都不算事」

## 角色关系

### 标配角色
- 神豪男主：有钱有颜，超宠妻
- 变心女友/老婆：后悔抱大腿
- 势利眼亲戚：各种跪舔
- 拜金女配：各种作妖
- 豪门家族：抛弃→求回归
- 各路大佬：巴结讨好

### 关系动态
- 身份隐藏 → 憋屈
- 身份曝光 → 打脸
- 家族求回归 → 拒绝/接受
- 老婆态度大转变
- 从被嘲笑到被仰望

## 情绪曲线

```
第一集：被嘲笑是穷鬼（憋屈）
第三集：展现实力（震惊）
第五集：身份逐渐曝光（爽）
第十集：疯狂打脸（超爽）
第十五集：家族求回归（拽）
第二十集：人生巅峰（爽）
```

## 常用叙事结构

1. **隐藏身份**：低调生活，被人嘲笑
2. **实力初现**：不经意间展现财力
3. **身份叠加**：马甲一层层掉落
4. **打脸高潮**：所有反派被收拾
5. **家族回归**：豪横回归家族
6. **圆满收官**：妻贤子孝，人生赢家
