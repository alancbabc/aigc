# 甜宠剧 Sweet Romance

## 核心主题
- 命中注定的相遇
- 青梅竹马的重逢
- 豪门总裁的专属宠溺
- 萌宝助攻的豪门婚姻
- 甜到掉牙的日常
- 护短宣言：「我的女人，谁也不能欺负」

## 典型设定

### 常见男主设定
- 豪门总裁（高冷、专一、宠妻）
- 青梅竹马（深情、守护、等待）
- 天才医生（温柔、细心、醋王）
- 顶流明星（公开宠妻、护妻狂魔）

### 常见女主设定
- 普通女孩（善良、独立、自强）
- 落难千金（隐藏身份、坚韧不屈）
- 职场小白（成长型、潜力股）
- 软萌甜妻（反差萌、隐藏实力）

### 经典套路
- 契约婚姻 → 假戏真做
- 相亲遇到真爱
- 醉酒误嫁豪门
- 萌宝带球跑
- 身份互换
- 追妻火葬场

## 爽点设计

### 甜蜜时刻
- 壁咚告白：「女人，你引起了我的注意」
- 公开官宣：「这是我老婆」
- 宠溺投喂：「乖，张嘴」
- 霸气护妻：「动她一下试试」
- 浪漫惊喜：「只要你想要，整个世界都给你」

### 打脸场面
- 绿茶挑衅 → 男主直接打脸
- 恶毒女配 →  被公开处刑
- 势利眼亲戚 → 被现实打脸
- 前任后悔 → 跪求复合被拒

### 高甜名场面
- 雨中撑伞
- 英雄救美
- 公主抱
- 背后拥抱
- 额头吻
- 婚戒誓言

## 角色关系

### 标配角色
- 甜宠男主：外冷内热，只对女主温柔
- 软萌女主：看似小白兔，实则有底线
- 助攻萌宝：聪明可爱神助攻
- 绿茶女配：各种作妖被打脸
- 恶毒婆婆：前期刁难后期认可
- 宠妻狂魔兄弟团：兄弟一起宠妻

### 关系动态
- 青梅竹马 → 日久生情
- 欢喜冤家 → 真香定律
- 先婚后爱 → 渐入佳境
- 契约恋爱 → 动真情
- 追妻火葬场 → 追妻成功

## 情绪曲线

```
第一集：相遇相知（甜+微虐）
第五集：确定关系（甜）
第十集：危机出现（虐）
第十五集：打脸高潮（爽）
第二十集：圆满结局（超甜）
```

## 常用叙事结构

1. **契约开局**：契约婚姻/相亲协议
2. **相处升温**：日常相处中发现对方优点
3. **危机出现**：绿茶/前任/家族阻力
4. **真相大白**：身份曝光/误会解除
5. **甜蜜升华**：官宣/结婚/生娃
