# 战神归来 Warrior Return

## 核心主题
- 隐藏身份，王者归来
- 退役兵王，都市纵横
- 豪门弃子，逆天改命
- 十年隐忍，一朝爆发
- 铁血柔情，护短到底
- 「犯我者，虽远必诛」

## 典型设定

### 常见男主设定
- 退役兵王（铁血战神、隐藏身份）
- 王牌特工（国际顶尖、回归都市）
- 隐世家族继承者（隐藏实力）
- 战场传奇（战功赫赫、选择归隐）

### 隐藏身份
- 战神/兵王
- 隐藏富豪
- 顶级黑客
- 医道圣手
- 暗网之主
- 神秘组织的王

### 经典套路
- 退役归来，发现妻女受辱
- 隐藏身份，被人轻视
- 身份曝光，打脸全场
- 家族危机，强势接管
- 敌人来犯，全部秒杀

## 爽点设计

### 打脸场面
- 狗眼看人低 → 当场跪舔
- 嘲讽废物 → 身份曝光吓尿
- 情敌挑衅 → 被秒成渣
- 家族抛弃 → 后悔莫及
- 敌人来犯 → 全部放倒

### 高燃时刻
- 一人之力灭全场
- 随手一个亿零花钱
- 各路大佬来跪舔
- 仇家跪求放过
- 身份一层层曝光

### 护短名场面
- 「动我女人一根汗毛试试」
- 「我女儿，谁也不能欺负」
- 「这个家，我回来了」
- 「从现在开始，我护着你们」
- 「敢动我的人，代价是什么」

## 角色关系

### 标配角色
- 战神男主：隐忍强大，护短满分
- 变心女友/前妻：后悔莫及
- 受辱妻女：等待救赎
- 恶毒家族：抛弃→求饶
- 各路敌人：全部秒杀
- 忠心下属：唯命是从

### 关系动态
- 归来的救赎
- 隐忍后的爆发
- 敌人的恐惧
- 家族的悔恨
- 曾经的嘲笑，如今的高攀不起

## 情绪曲线

```
第一集：归来看见妻女受辱（怒）
第三集：隐藏身份被嘲讽（憋屈）
第五集：第一次出手震慑（爽）
第十集：身份逐渐曝光（爽）
第十五集：打脸反派高潮（超爽）
第二十集：巅峰回归（燃）
```

## 常用叙事结构

1. **归来做局**：退役归来，看到惨状
2. **隐忍观察**：假装废物，暗中布局
3. **小试牛刀**：展现实力，震慑全场
4. **身份曝光**：一层层马甲掉落
5. **巅峰打脸**：敌人跪服，家族悔恨
6. **圆满结局**：妻女认可，圆满收官
