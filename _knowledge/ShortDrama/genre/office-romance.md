# 职场甜恋 Office Romance

## 核心主题
- 职场小白成长记
- 实习生的逆袭之路
- 总裁与特助的日常
- 冤家路窄到日久生情
- 办公室恋情
- 「因为你，我成为了更好的人」

## 典型设定

### 常见职场设定
- 职场小白（实习生/新人）
- 精英律师/医生/霸总
- 面试被刁难
- 职场潜规则
- 竞争对手变恋人

### 经典套路
- 面试遇到未来老公
- 实习期各种被刁难
- 加班加出感情
- 冤家变恋人
- 办公室恋情公开
- 共同面对职场危机

## 爽点设计

### 成长逆袭
- 菜鸟变精英
- 提案惊艳全场
- 搞定大客户
- 升职加薪
- 打脸看轻自己的人

### 甜蜜场面
- 总裁特批假期
- 专属便当
- 加班陪送回家
- 生病时的照顾
- 公开恋情

### 打脸场面
- 绿茶同事被收拾
- 势利眼被打脸
- 前男友后悔
- 情敌自动退散

## 角色关系

### 标配角色
- 成长型女主：努力上进
- 毒舌霸总：外冷内热
- 绿茶同事：各种作妖
- 贴心闺蜜：神助攻
- 霸道婆婆：前期反对后期认可

### 关系动态
- 面试初遇 → 互相看不顺眼
- 相处了解 → 日久生情
- 危机并肩 → 感情升温
- 公开恋情 → 甜蜜撒糖

```
第一集：面试相遇（有趣）
第三集：进入公司（期待）
第五集：相处了解（甜）
第十集：危机并肩（感动）
第十五集：确定关系（甜）
第二十集：甜蜜收官（圆满）
```

## 常用叙事结构

1. **面试相遇**：奇葩面试官
2. **进入职场**：各种挑战
3. **成长蜕变**：能力提升
4. **感情升温**：日久生情
5. **危机共同面对】：患难见真情
6. **甜蜜收官**：事业爱情双丰收
